# OneFam Dance Studio Website

A responsive, luxury-themed single-page website built with HTML, CSS and JavaScript.

## Run in VS Code
1. Extract `OneFam_Dance_Studio.zip`.
2. Open the `OneFam_Dance_Studio` folder in Visual Studio Code.
3. Open `index.html` in your browser, or install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.

## Files
- `index.html` — website structure and content
- `styles.css` — luxury dark, gold and cream styling; responsive layout
- `script.js` — mobile navigation and enquiry email form

## Before publishing
- Replace the sample Unsplash photographs in `index.html` and `styles.css` with photos owned by OneFam, especially real student participation, college events, cinema projects and performances.
- Confirm the class details, show history, vacancy terms and address spelling.
- The enquiry form opens the visitor's email app with a pre-filled message. It does not store submissions or send email automatically.
- Google Fonts and sample photographs load from the internet.
- Deploy using any static website host (for example, GitHub Pages, Netlify or your hosting provider).
